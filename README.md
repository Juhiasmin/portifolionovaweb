# NOVA/WEB — site institucional responsivo

Projeto inicial em HTML, CSS e JavaScript puro.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `styles.css`: identidade visual e responsividade.
- `script.js`: menu mobile, animações de entrada e formulário que abre o WhatsApp.

## Antes de publicar
1. Escolha e confirme o nome da marca. `NOVA/WEB` é provisório.
2. No `script.js`, substitua `WHATSAPP_NUMBER` pelo número real com código do país e DDD, somente números.
3. Atualize textos, e-mail, redes sociais e informações comerciais conforme necessário.
4. Confira os projetos: os dois exemplos são conceituais/fictícios e devem permanecer identificados assim até serem substituídos por trabalhos reais.
5. Teste todos os links e o formulário em celular e computador.

## Como visualizar
Abra `index.html` no navegador. Para desenvolvimento, você também pode usar a extensão Live Server no VS Code.

## Observações
- O formulário não envia dados para um servidor: ele monta uma mensagem e abre o WhatsApp.
- As fontes são carregadas do Google Fonts; se o visitante estiver offline, serão usadas fontes alternativas.
- O projeto não inclui backend, banco de dados ou domínio.
